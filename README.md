# OrbitAI

Your AI-powered MongoDB Atlas mission control.

OrbitAI is an MCP server that exposes MongoDB Atlas Admin API capabilities through natural language. It enables platform teams, DevOps engineers, and administrators to manage Atlas infrastructure conversationally via MCP clients, a CLI, or a web UI.

## Capabilities

- **Cluster Management** - Create, scale, pause, resume, and configure clusters across AWS, Azure, and GCP
- **Security & Access** - Database users, custom roles, IP allow lists, network peering, private endpoints, encryption, LDAP, and auditing
- **Monitoring & Alerts** - Real-time metrics, performance advisor, slow query analysis, and third-party integrations
- **Backup & Recovery** - Snapshots, point-in-time restore, backup compliance, and export to cloud storage
- **Atlas Services** - Search indexes, Vector Search, Data Lake, Online Archive, Triggers, Functions, and Streams
- **Billing & Cost** - Invoices, usage tracking, cost analysis, and budget alerts
- **Org & Project Admin** - Organizations, projects, teams, API keys, and federated authentication

## Tech Stack

- TypeScript + MCP SDK
- MongoDB Atlas Admin API v2.0
